# Simple export (same engine as the extension)

If you prefer not to install the extension, paste `console-export.js` into the
DevTools console on a share link. Same API, same transcript.

**Preferred path is still the extension** — see the README (share link + Incognito).

## Console fallback

1. Share the chat → open the share URL (Incognito is fine)
2. F12 → Console → paste `console-export.js` → Enter
3. `.md` downloads / clipboard copy when allowed → paste into Word
